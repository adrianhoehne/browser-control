browser-control turns your own Firefox into an MCP server for agents, and this
folder needs no installation.
Unzip the folder, run start.sh on Linux or start.cmd on Windows, and leave the
window open: it shows the endpoint, the MCP address and the token.
Read FIREFOX.md to load the extension, then CLIENTS.md to connect your MCP
client; both guides are in this folder.
Nothing is written outside this folder, and the token in data/token is created
on the first start and kept from then on.
